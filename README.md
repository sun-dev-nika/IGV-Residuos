# IGV Residuos

Sitio web para IGV Residuos, empresa dedicada a la gestión y tratamiento de residuos.

## Tecnologías

- HTML / CSS / JavaScript
- Desplegado en [Vercel](https://vercel.com)

## Demo en vivo

[igv-residuos.vercel.app](https://igv-residuos.vercel.app)

## Desarrollo local

```bash
git clone https://github.com/sun-dev-nika/IGV-Residuos.git
cd IGV-Residuos
```

Abrir `index.html` en el navegador, o servir la carpeta con cualquier servidor estático.

## Deploy

Este proyecto está conectado a Vercel. Cada `git push` a la rama `main` actualiza el sitio en producción automáticamente.
